# 유별난PPT 홈페이지 v3

2026-10-24 개발 버전. 기존 공개 홈페이지와 분리한 새 방향입니다. ANCORS의 화면 리듬을 참고해 유별난PPT의 장표·인쇄물·디지털 제작 오브젝트로 구성했습니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 실행합니다. 사이트 실행용 외부 패키지는 없습니다.

```sh
npm run build
npm start
```

브라우저에서 `http://127.0.0.1:4185/`를 엽니다. HTML 파일을 직접 더블클릭하는 방식은 ES module 실행을 지원하지 않습니다.

## 구성 (v4 리디자인, 2026-10-24)

홈은 ANCORS의 화면 리듬(한 화면 한 메시지, 거대 타이포 위의 오브젝트)과 코어플랫폼의 다크 섹션·작업 벽을 섞어, 블루 + 블랙으로 다시 만들었습니다. 이전 Codex 작업 원본은 `_backup-codex/`에 그대로 있습니다.

- `src/home.mjs`: 홈 전체 마크업 (10개 장면)
- `public/home.css`: 홈 전용 스타일, `public/motion.mjs`: 스크롤·인터랙션
- `public/styles.css`: 공통 헤더·푸터·하위 페이지 스타일
- `src/render.mjs`, `src/copy.mjs`: 레이아웃과 하위 페이지
- `src/data.mjs`: 연락처·가격·옵션·FAQ·진행 단계 (홈 문구도 이 데이터를 그대로 사용)
- `src/portfolio.mjs`: 공개 작업 36건과 원본 비율
- `public/assets/concepts/`: 장식용 생성 오브젝트 5종 (실제 고객 사례 아님)
- `dist/`: 빌드 결과

`src/editorial.mjs`, `public/editorial.css`, `public/editorial-motion.mjs`는 v4에서 쓰지 않는 빈 파일입니다. 지워도 됩니다.

## 홈 장면 순서 (스크롤 약 8.5화면)

1. **첫 화면** — "같은 초안도 / 급한 IR도 / 줄글 메모도 / AI로 뽑은 장표도," 가 바뀌고 아래에 거대한 **유별나게.** 장표 오브젝트가 마우스를 따라 살짝 움직임
2. **블랙 콜라주** — 첫 화면 위로 덮이며 올라옴. "좋은 아이템이, 자료 때문에 작아 보이지 않게."
3. **진행 과정** — 한 화면 안에서 4단계를 고르면(또는 자동) 오른쪽 장표가 초안→흐름 시안→디자인·피드백→PPTX/PDF로 바뀜
4. **제작 범위** — DECK / PRINT / WEB / VISUAL / TOOLS 거대 단어 위 오브젝트, 탭·화살표·자동 전환
5. **작업 사례** — 검은 배경, 실제 공개 작업 36건 썸네일 벽 (클릭 시 상세)
5-1. **숫자와 고객사** — 기존 홈에 있던 누적 작업 800+ · 클라이언트 300+ · 평균 만족도 4.9/5 · 공식 후기 458+ (ANCORS식 숫자 행), 함께한 기업·기관 로고 흐름 띠. `src/data.mjs`의 `stats`, `partnerLogos`, `partnerNames`
6. **데모데이** — 맡았던 데모데이 7건(연혁) 목록 + "데모데이 한 번에 포함되는 것" 6가지 서비스 + 추가 옵션. `demodayHistory`
6-1. **후기** — 기존 홈의 실제 후기 7개를 가로 슬라이드로. `reviews`
7. **서비스와 가격** — 베이직 / 프로 / 프리미엄 가격표. 위 단계일수록 포함 항목이 누적됨. 가격 칸은 `src/data.mjs`의 `status`가 `approved`일 때 금액 표시, 지금은 "자료 확인 후 견적"
8. **FAQ → 마무리 + 푸터**

각 장면은 한 화면 안에서 끝나도록 잡았고, 스크롤을 붙잡아 길게 내리게 하는 구간은 없습니다. 구분선 대신 여백과 면으로 나눴습니다.

모션 감소 설정이면 자동 전환·패럴랙스가 꺼지고 정적으로 읽힙니다. 휠은 가로채지 않습니다. JavaScript가 없어도 내용·가격·FAQ가 모두 보입니다.

## 배포

공개 사이트에는 아직 배포하지 않았습니다. 이 파일은 개발용 소스입니다.

검토 후 정적 호스팅에는 `dist/`의 **내용**을 배포합니다. ZIP 파일 자체를 올려서는 홈페이지가 실행되지 않습니다. 모든 로컬 경로는 상대 경로이므로 GitHub Pages의 저장소 하위 폴더에서도 사용할 수 있습니다. 공개 모드에서는 `SITE_MODE=production`으로 빌드하여 빈 GIF의 편집 안내를 숨길 수 있습니다.

Windows PowerShell 공개용 빌드:

```powershell
$env:SITE_MODE='production'
npm run build
Remove-Item Env:SITE_MODE
```

## 운영 전 남은 연결

문의 API와 실제 개인정보 안내가 아직 연결되지 않아 폼 접수 버튼은 비활성 상태입니다. 카카오톡 상담은 연결돼 있습니다. 일반 PPT 가격과 홈페이지 옵션 가격은 제안 상태이므로 공개 금액으로 표시하지 않습니다. GIF 4개는 요청대로 빈 상태입니다. 상세 설정과 API 계약은 `OPERATIONS.md`를 참고하세요.

생성 이미지는 실제 고객의 작업·실적과 구분했습니다. 초안 완성 과정의 DOM 장표는 같은 내용을 사용한 자체 구성 예시입니다. 출처와 생성 기록은 `ASSETS.md`, `GENERATION.md`에 있습니다.

npm test

`scripts/qa.mjs`는 브라우저 QA 스크립트입니다. `npm i -D playwright` 후 `node scripts/qa.mjs`로 실행합니다(설치된 Chrome을 쓰려면 `CHROME_PATH` 지정). 사이트 자체에는 필요 없습니다. 결과 화면은 `qa/`에 저장됩니다.
