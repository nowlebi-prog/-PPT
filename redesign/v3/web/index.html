가격 안내
표기 금액은 부가세 별도 시작가입니다. 최종 비용은 콘텐츠 분량과 기능 범위를 확인한 뒤 안내합니다.
제작 기준
고객이 제공한 원고와 이미지, 기존 디자인 구성을 기준으로 제작합니다. 수정 1회는 취합된 요청 1건을 기준으로 하며, 확정 후 구성 변경과 신규 기능 추가는 별도 견적입니다.
운영 비용
