가격 안내
표기 금액은 부가세 별도 시작가입니다. 최종 비용은 콘텐츠 분량과 기능 범위를 확인한 뒤 안내합니다.
제작 기준
고객이 제공한 원고와 이미지, 기존 디자인 구성을 기준으로 제작합니다. 수정 1회는 취합된 요청 1건을 기준으로 하며, 확정 후 구성 변경과 신규 기능 추가는 별도 견적입니다.
운영 비용
도메인·호스팅·유료 폼 서비스 등 외부 서비스 이용료는 별도입니다. 운영 기간과 연장 비용은 계약 시 안내합니다. 신청자 응대·명단 관리·상시 운영 대행은 포함되지 않습니다.

폼 연동형은 외부 서비스의 지원 범위 내에서 제공하며, 별도 관리자 시스템 개발은 포함되지 않습니다.
