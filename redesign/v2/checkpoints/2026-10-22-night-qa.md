## 고친 것
**모바일**
- 320px: 첫 화면 버튼 줄바꿈 → 세로 배치, 숫자 "642건+"의 "+" 줄바꿈 방지, 성함·회사명 한 줄씩, 로고 영문 숨김
- 모바일 섹션 머리글을 모두 같은 왼쪽 선으로 (가운데·왼쪽 섞여 있던 것)
- 태블릿(601–860px) 제목 사이 빈 줄 생기던 문제
- 헤더 버튼·햄버거·푸터 링크·연락처 링크 터치 영역 44px 확보
- 가격 공통 포함 안내 10.5px → 12px
- placeholder가 잘리던 문제 ("이름을 입력하세" → "이름")

**기능·접근성**
- 빠른 견적·준비 가이드·모바일 메뉴·포트폴리오 라이트박스: Tab 키가 창 밖으로 나가지 않게, 닫으면 원래 위치로 포커스 복귀
- 어두운 배경에서도 보이는 키보드 포커스 표시
- 빠른 견적 결과가 이미 쓴 문의 내용이 있으면 버려지던 문제 → 뒤에 덧붙임
- 개인정보 동의 미체크 시 빨간 표시
- 메뉴 Esc·화면 회전이 다른 창의 스크롤 잠금을 풀던 문제
- 메일 앱이 없는 기기 대비: 제출 후 "문의 내용 복사" + 카카오톡 안내
- Safari용 `-webkit-backdrop-filter` 누락분 보완

**톤앤매너**
- "공식 고객후기" → "고객 후기" (about 포함), 헤더 Portfolio/Contact → 포트폴리오/문의 (세 페이지)
- FAQ 답변 중 하나만 "~어요"체 → "~습니다"체로 통일 (UI 안내 토스트는 "~어요" 유지)
- 문의 영역 eyebrow 자간 규칙이 준비 가이드 카드 설명까지 번지던 문제

**검색·공유·속도**
- 탭 제목이 "유별난PPT 시안 v2 — 빛"으로 노출되던 것 → 정식 제목
- description · OG(카톡·슬랙 공유 미리보기) · 파비콘 추가
- 시안 경로라 `noindex` 설정 — **정식 오픈 때 `<meta name="robots" content="noindex">` 세 줄 삭제**

## 확인 못 한 것 / 판단 필요
- 실제 아이폰 Safari: 이 환경에서 WebKit 설치가 막혀 크롬 모바일 에뮬레이션으로만 확인. 접두어 등 정적 점검은 함.
- 3D 발표장·첫 화면 빛(three.js·WebGL)은 테스트 환경에서 외부 CDN이 막혀 대체 화면으로만 확인.
- 루트(현재 운영 중) `index.html` 메타 설명에 "크몽 거래 442건"이 남아 있음 — v2 규칙상 금지 표현이지만 운영 페이지라 손대지 않음.
